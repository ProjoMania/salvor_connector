# Salvor Connector 2.0.7

Documentation and store metadata only; the code is the same as 2.0.6.

## What changed
- `SECURITY.md`: advisory SC-2026-01 is published as
  [GHSA-qxmx-8p3v-m6x3](https://github.com/ProjoMania/salvor_connector/security/advisories/GHSA-qxmx-8p3v-m6x3); releases are SSH-signed tags
  (`17.0-2.0.4` … `20.0-2.0.6`, and `<series>-2.0.7` for this one).
- Support contact **support@salvorcloud.com** (README, store page, manifest `support` key) next to
  **security@salvorcloud.com** for private vulnerability reports.
- Store screenshots in `static/description/` and the manifest `images` list: settings (not paired,
  connected), Pull Log, settings menu. They were taken on Odoo 19.0; every branch ships the same images.

## Upgrade
Optional from 2.0.6 (nothing functional changed). From anything older, follow `docs/release/2.0.6.md`.

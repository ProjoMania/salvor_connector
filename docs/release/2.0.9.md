# Salvor Connector 2.0.9

Documentation, store page and CI only; the code is the same as 2.0.6.

## What changed
- Store page: one upgrade sentence near the top: "Always use the latest version. If you are upgrading
  from 1.0.0, 2.0.0 or 2.0.1, pair the module again after upgrading. Details: SECURITY.md."
- `SECURITY.md`: a copy-paste-ready allowed-signers line with the release signing public key, and the
  `git verify-tag` command that uses it.
- CI: `.github/workflows/conflict-markers.yml` runs `scripts/check-conflict-markers.sh` on every push
  and pull request.
- `TAGS.md`: 2.0.8 hashes and the 2.0.9 row.

## Upgrade
Optional from 2.0.6 or later (nothing functional changed). From anything older, follow
`docs/release/2.0.6.md`.

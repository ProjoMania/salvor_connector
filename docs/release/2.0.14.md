# Salvor Connector 2.0.14

**No change to how the module works.** The backup, pairing, token and allowlist code is the code of
2.0.13, byte for byte. This release changes what the store page and the settings form say.

Upgrading from 2.0.13 is optional. If you are on anything older, read `docs/release/2.0.13.md` first.

## What changed

- **Store listing.** New module title ("Salvor Connector: Off-site Database Backup without the Master
  Password") and summary, so the module can be found by what it does; the store searches the title and
  the summary only. The menu, the form title and the views keep the name "Salvor Connector".
- **Description page.** The opening line about the Pull Log now says what the technical section says
  (Salvor's calls and refusals, not "every" one). New sections at the top: what this free module does, what a Salvor account adds
  (Salvor is a paid service with a free trial), where restore drills run, and how to get started. The
  technical sections are unchanged. The Odoo 16 mentions are gone from this branch's page (16.0 has its
  own branch), and the upgrade steps moved into a last "Upgrading" item.
- **Images.** A 2:1 cover and two new screenshots (the backups of a database in Salvor, and the e-mail
  Salvor sends when backups stop arriving). `screenshot_1_settings_unpaired.png` was taken again.
- **Settings form, before pairing.** The "Not connected" notice now ends with: "No Salvor account yet?
  Create one (14-day free trial, no card), then come back here with the pairing code." "Create one" is
  a link to salvorcloud.com that opens in a new tab. The module itself still makes no call to that
  address: it is a link a person may click.
- **Website field.** The manifest's `website` carries a source tag
  (`?utm_source=odoo-apps&utm_medium=marketplace&utm_campaign=connector-listing`), and the link in the
  settings form carries `utm_source=odoo-module`. Both lead to https://salvorcloud.com/ and carry a tag
  that says where the visit came from (the store listing or the module's settings form), which Salvor's
  site passes on to sign-up. Nothing about your Odoo is in them.

## What did not change

Python, controllers, the background job, security rules, data files, cron, the protocol, the token and
the IP allowlist. `git diff 20.0-2.0.13 20.0-2.0.14 -- salvor_connector/*.py salvor_connector/controllers
salvor_connector/models salvor_connector/security salvor_connector/data` shows only the manifest's
`name`, `summary`, `version`, `website` and `images`.

## Tests

The module's test suite passes on Odoo 17, 18, 19 and 20 with this release (the counts are in the
release commit message).

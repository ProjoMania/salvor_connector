# Salvor Connector 2.0.8

Documentation and store page only; the code is the same as 2.0.6 and 2.0.7.

## What changed
- **Store page fix (17.0, 18.0, 20.0):** 2.0.6 and 2.0.7 shipped `static/description/index.html` with
  unresolved merge-conflict markers inside the security advisory box (the SECURITY.md link appeared
  twice). The page now matches 19.0. A module test and `scripts/check-conflict-markers.sh` (usable as a
  pre-push hook) now fail on any conflict-marker line.
- Store page: the security-advisory box at the top is removed; the advisory stays in `SECURITY.md`,
  the README and GitHub advisory GHSA-qxmx-8p3v-m6x3. The page ends with a one-line support contact and
  a link to `SECURITY.md`.
- Store page: the four screenshots are shown, the connected settings form first (also first in the
  manifest `images`, so it is the cover).
- `SECURITY.md`: names the release signing key for `git verify-tag` (ED25519
  `SHA256:xZlGFj2cTC7LTGMxb0YDlfE1J+GC1gakO807ffiw0VE`, "salvor_connector release signing",
  `security@salvorcloud.com`) and explains that the advisory's "patched 2.0.2" means not exploitable
  from 2.0.2, while 2.0.4 removed the code.
- Release notes, GHSA draft and `TAGS.md` no longer say tags are still to be created.

`docs/release/2.0.6.md`.

# Salvor Connector 2.0.15

**No change to how the module works.** Every Python, view, security and data file is the file of 2.0.14,
byte for byte. This release changes two texts of the store listing.

Upgrading from 2.0.13 or 2.0.14 is optional. If you are on anything older, read
`docs/release/2.0.13.md` first.

## What changed

- **Summary.** The manifest's one-line summary now reads: "Automatic backup of this Odoo database: an
  off-site backup with verification, through a Salvor account (free trial). No master password; works
  with list_db = False." It says the same as before, in words people search the store for.
- **Description page, "Get started".** The steps are in the order you do them: create a Salvor account,
  install this module, take the pairing code in Salvor, paste it in Odoo and click Connect, see the
  result of the connection test. The pairing code is valid for 10 minutes, so it is taken after the
  module is installed, not before. The list has five steps where it had four.

## What did not change

Python, controllers, the background job, views, security rules, data files, cron, the protocol, the
token and the IP allowlist. `git diff 19.0-2.0.14 19.0-2.0.15 -- salvor_connector` shows the
manifest's `summary` and `version` and the "Get started" list of `static/description/index.html`.

## Tests

The module's test suite passes on Odoo 17, 18, 19 and 20 after an upgrade from 2.0.14 to this release
(the counts are in the release commit message).
